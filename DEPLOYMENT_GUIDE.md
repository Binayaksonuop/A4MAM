# Spirulina MAM - Production Deployment Guide

This guide details the steps to migrate from local development to a production cloud environment.

---

## 1. MongoDB Atlas (Database Cloud)
1.  **Create Cluster**: Sign up at [mongodb.com](https://www.mongodb.com/) and create a free Shared Cluster.
2.  **Network Access**: Whitelist `0.0.0.0/0` (Allow access from anywhere) in the Network Access tab.
3.  **Database User**: Create a user (e.g., `a4mam_admin`) with a strong password.
4.  **Connection String**: Copy the SRV string: `mongodb+srv://<user>:<password>@cluster.mongodb.net/a4mam?...`

---

## 2. Render (Backend Deployment)
1.  **New Web Service**: Connect your GitHub repository to [Render.com](https://render.com/).
2.  **Root Directory**: `backend`
3.  **Build Command**: `npm install`
4.  **Start Command**: `npm start` (or `node server.js`)
5.  **Environment Variables**:
    -   `MONGO_URI`: (Your Atlas SRV string)
    -   `JWT_SECRET`: (A strong random string)
    -   `NODE_ENV`: `production`
    -   `ADMIN_EMAIL`: (e.g., admin@a4mam.org)
    -   `ADMIN_PASSWORD`: (Your admin password)

---

## 3. Frontend Deployment (Vercel/Netlify/Firebase)
1.  **Update API URL**: In `src/environments/environment.prod.ts`, update `apiUrl` to your Render URL: `https://your-backend.onrender.com/api`.
2.  **Build Project**: Run `npm run build` in the root directory.
3.  **Deploy `dist/mam`**: Upload the contents of the `dist/mam` folder to your static hosting provider.
4.  **CORS**: Ensure your frontend URL (e.g., `https://a4mam.vercel.app`) is added to the `allowedOrigins` list in `backend/server.js`.

---

## 4. Final Production Checklist
- [ ] **MongoDB Whitelist**: IP `0.0.0.0/0` is added to Atlas.
- [ ] **Environment Variables**: All keys from `.env.example` are set on Render.
- [ ] **Production Build**: `npm run build` executed successfully.
- [ ] **API Sync**: Frontend `apiUrl` matches Backend deployment URL.
- [ ] **Seed Data**: Run `npm run seed` locally with the Cloud URI once to populate the production DB.
- [ ] **SSL**: Ensure all links use `https`.
